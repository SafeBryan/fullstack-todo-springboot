# Lab 01 - Shopping List HTML

## Course

Full-Stack Web Development - Course 5

## Module

Module 1 - Frontend Development

## Description

This lab consists of creating a basic HTML webpage for a shopping list. The page includes shopping categories, unordered lists, nested lists, internal hyperlinks, and a navigation section.

## Objective

Create a nested shopping list and add internal hyperlinks between item names and their corresponding descriptions. Also, include a navigation menu that allows the user to move between different shopping categories.

## Implemented tasks

- Added a `Food Items` section using an `h2` tag with `id="food"`.
- Created an unordered list of food items.
- Added a nested unordered list under `Fruits`.
- Added an `Electronics Items` section using an `h2` tag with `id="electronics"`.
- Created an unordered list of electronics items.
- Added item descriptions for `Apples` and `Television`.
- Added internal hyperlinks from list items to their descriptions.
- Added a navigation section using the `nav` tag.
- Added a link to return to the top of the page.
