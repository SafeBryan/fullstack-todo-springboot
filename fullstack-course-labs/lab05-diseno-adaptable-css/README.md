# Laboratorio 05 - Diseño adaptable con CSS, Flexbox y animaciones

## Curso

Desarrollo Web Full Stack - Curso 5

## Módulo

Módulo 1 - Desarrollo Frontend

## Descripción

Este laboratorio consiste en mejorar la experiencia de usuario de un sitio web de lista de compras mediante CSS adaptable. Se implementó una barra lateral para pantallas móviles, se utilizó Flexbox para organizar un formulario de comentarios y se añadieron transiciones y animaciones CSS para mejorar la interacción visual.

## Objetivo

Crear un sitio de compras adaptable utilizando Flexbox para diseños responsivos e implementar transiciones y animaciones CSS para mejorar la interacción del usuario.

## Archivos incluidos

- `login.html`
- `feedback.html`
- `css/sidebar.css`
- `css/feedback.css`

## Funcionalidades implementadas

- Creación de una estructura de navegación superior para pantallas grandes.
- Creación de una barra lateral para pantallas pequeñas.
- Ocultamiento de la barra lateral por defecto.
- Uso de media query para mostrar la barra lateral cuando la pantalla es menor o igual a 768px.
- Ocultamiento de la barra de navegación superior en vista móvil.
- Organización del formulario de comentarios con Flexbox.
- Alineación vertical de los campos del formulario.
- Alineación horizontal de botones mediante Flexbox.
- Uso de `justify-content: space-between` para separar botones.
- Implementación de animación de entrada con `@keyframes`.
- Aplicación de animación `slideIn` al formulario.
- Uso de transiciones en botones con efecto `hover`.
- Adaptación de botones en columna para pantallas pequeñas.
