# Lab 02 - HTML Registration Form

## Course

Full-Stack Web Development - Course 5

## Module

Module 1 - Frontend Development

## Description

This lab consists of creating a registration form using HTML. The form collects user information such as name, user ID, password, email address, correspondence address, gender, shopping preferences, and registration category.

The lab also includes semantic HTML elements such as `nav` and `footer` to improve the structure and navigation of the webpage.

## Objective

Develop an HTML web form using text, password, and email input fields, a textarea for multi-line text, radio buttons, checkboxes, a dropdown list, navigation links, and a footer section.

## Implemented tasks

- Created a registration form using the `form` tag.
- Set the form action to `#` and method to `POST`.
- Added a text input for the user's name.
- Added a text input for the user ID.
- Added a password input field.
- Added an email input field.
- Added a textarea for the correspondence address.
- Added radio buttons for gender selection.
- Added checkboxes for shopping preferences.
- Added a dropdown list for registration category.
- Added a submit button.
- Added a navigation section using the `nav` tag.
- Added links to Home, Login, and Categories pages.
- Added a footer with copyright information.
