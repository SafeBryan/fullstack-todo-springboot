# Laboratorio 03 - Navegación entre páginas HTML

## Curso

Desarrollo Web Full Stack - Curso 5

## Módulo

Módulo 1 - Desarrollo Frontend

## Descripción

Este laboratorio consiste en crear la estructura básica de un sitio web de lista de compras con varias páginas HTML. El objetivo principal es implementar hipervínculos entre páginas y enlaces internos dentro de una misma página.

El sitio incluye cuatro páginas principales: inicio, registro, inicio de sesión y categorías de compras.

## Objetivo

Proporcionar hipervínculos a cada página para facilitar la navegación, establecer enlaces internos hacia secciones específicas de una página y construir distintos tipos de enlaces HTML.

## Archivos incluidos

- `index.html`
- `registration.html`
- `login.html`
- `categories.html`

## Funcionalidades implementadas

- Creación de una página de inicio.
- Creación de una página de registro.
- Creación de una página de inicio de sesión.
- Creación de una página de categorías.
- Navegación entre las cuatro páginas mediante etiquetas `<a>`.
- Enlace desde la página de registro hacia la página de inicio de sesión.
- Enlace desde la página de inicio de sesión hacia la página de registro.
- Lista desordenada de alimentos.
- Lista desordenada de productos electrónicos.
- Lista anidada dentro de la categoría Frutas.
- Enlace interno desde el elemento Manzanas hacia su descripción.
- Enlace interno para volver a la parte superior de la página.

## Etiquetas HTML utilizadas
