# Laboratorio 04 - Estilos CSS para formularios, tablas y botones

## Curso

Desarrollo Web Full Stack - Curso 5

## Módulo

Módulo 1 - Desarrollo Frontend

## Descripción

Este laboratorio consiste en aplicar estilos CSS internos y externos para mejorar la apariencia de formularios, tablas y botones dentro de una aplicación web de lista de compras.

Se trabajó con archivos CSS externos para mantener una mejor organización del diseño y también con CSS interno para aplicar estilos específicos en una página determinada.

## Objetivo

Aplicar CSS a páginas HTML para mejorar la presentación visual, la legibilidad y la experiencia del usuario mediante estilos en formularios, tablas y botones.

## Archivos incluidos

- `login.html`
- `categories.html`
- `feedback.html`
- `css/form-styles.css`
- `css/color-scheme.css`

## Funcionalidades implementadas

- Vinculación de una hoja de estilos externa en `login.html`.
- Aplicación de estilos a campos de formulario.
- Uso de fondo gris claro en campos de texto, contraseña y correo electrónico.
- Aplicación de bordes, relleno y esquinas redondeadas.
- Estilización de tablas en `categories.html`.
- Aplicación de relleno de 10px a celdas de tabla.
- Estilización de encabezados de tabla con fondo azul, texto blanco y negrita.
- Uso de CSS interno en `feedback.html`.
- Estilización de botones de envío y borrado.
- Implementación de efectos `hover` en botones.
- Mejora general de la legibilidad y presentación visual.
