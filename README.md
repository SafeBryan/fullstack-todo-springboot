# Full-Stack Web Development Course - To-Do Application

## Description

This repository contains the learning evidence, laboratory activities, and final project developed as part of the Full-Stack Web Development course.

The main final project of the course is a full-stack To-Do web application. This application will allow users to register, log in, manage personal tasks, classify them by priority, mark them as completed, and securely access only their own information.

## Course objective

The objective of this course is to develop practical skills in full-stack web development by integrating frontend technologies, backend development with Java and Spring Boot, RESTful APIs, security, and dynamic web views.

## Technologies

- HTML
- CSS
- JavaScript
- Java
- Spring Boot
- Spring Security
- Maven
- Thymeleaf
- RESTful APIs
- H2 / MySQL Database
- Git and GitHub
