# Full-Stack Web Development Course

## Description

This repository contains the learning evidence, laboratory activities, and final project developed during the **Full-Stack Web Development** course.

Throughout the course, different full-stack development concepts were practiced, including frontend development, backend development with Java and Spring Boot, RESTful APIs, database integration, security, testing, and basic cloud deployment concepts.

## Modules Covered

### Module 1: Frontend Fundamentals

In this module, the main concepts of frontend development were reviewed and practiced.

Topics covered:

- HTML structure
- CSS styling
- Responsive design
- JavaScript basics
- DOM manipulation
- Forms
- Client-side validation
- Basic web page interaction

### Module 2: Java Web Development

In this module, Java web development was studied using technologies commonly applied in backend and dynamic web applications.

Topics covered:

- Java Servlets
- JSP
- Spring Boot
- Spring MVC
- Thymeleaf
- Spring Data JPA
- Spring Security
- Role-based access control
- Spring Boot Actuator
- CRUD operations
- MVC architecture

### Module 3: Web APIs and Cloud Deployment

In this module, RESTful services and API integration were developed, including frontend communication with backend services and basic cloud deployment concepts.

Topics covered:

- RESTful services
- HTTP methods: GET, POST, PUT and DELETE
- Postman for API testing
- Error handling in APIs
- Data validation
- HATEOAS
- Fetch API
- Axios
- Frontend and backend integration
- AWS basics
- EC2
- RDS
- S3
- Lambda

## Final Project

The final project of the course is a full-stack web application called **ToDo Rails**.

This application allows users to manage personal tasks through a secure and responsive web interface.

Main features:

- User registration
- User login
- Protected pages with Spring Security
- Task creation
- Task editing
- Task visualization
- Task deletion
- Task completion tracking
- Task priority classification
- Dashboard with pending and completed tasks
- Responsive interface

## Purpose

The purpose of this repository is to keep organized evidence of the practical work completed during the course and to demonstrate the development of full-stack web development skills.

It also serves as a personal portfolio of the learning process, showing the progression from basic frontend development to backend development with Spring Boot, RESTful API creation, security implementation, database integration, and final project development.
