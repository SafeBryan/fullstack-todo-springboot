# Aplicación Web Full Stack - Gestión de Tareas

## Descripción
Aplicación web desarrollada como proyecto final del curso de Desarrollo Web Full Stack. Permite registrar usuarios, iniciar sesión y gestionar tareas personales con prioridad y fecha límite.

## Tecnologías utilizadas
- Java
- Spring Boot
- Spring Security
- Maven
- Thymeleaf
- HTML
- CSS
- JavaScript
- Base de datos H2/MySQL

## Funcionalidades
- Registro de usuarios
- Inicio de sesión
- Dashboard personalizado
- Crear tareas
- Editar tareas
- Eliminar tareas
- Marcar tareas como completadas
- Clasificación por prioridad
- Cambio de contraseña
- Seguridad por usuario
